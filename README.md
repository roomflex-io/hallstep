# Hallstep

UK wedding halls directory. Choose ceremony type (all major religions), city or local area, and a loose date window. Then see available halls.

Live: after Vercel deploy.

## Stack
- Static site on Vercel
- GitHub: roomflex-io/hallstep
- Supabase: not connected in this chat (no Supabase connector). Create a project at supabase.com and add halls in a `halls` table to replace the sample list.
